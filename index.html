Introduction

Professional Self-Assessment

I have gained experience in software development, programming, databases, algorithms, and security during my time in Southern New Hampshire University's Computer Science program. My confidence in resolving technical issues and being ready for a career as a software engineer has increased since completing this program. My ePortfolio shows what I have learned and how I have improved projects throughout my education. I have learned the value of teamwork and communication in software development from my courses. I now know how to document my work, explain technological decisions, and take stakeholders' and users' demands into account. I have developed my communication abilities through software design documentation, code reviews, and project planning, which will help me collaborate with other engineers and contribute to professional projects. Also, I now have more expertise in software engineering, algorithms, and data structures. Python, JavaScript, Java, and C++ have all been used in my projects. I now know how to arrange code, enhance functionality, and create programs that address real-world issues. My understanding of how various technologies collaborate to provide comprehensive software solutions has improved thanks to courses on web development and mobile applications. Another significant aspect of my studies has been database building. I now have a better understanding of how to efficiently save, retrieve, update, and delete data thanks to my work with Python and MongoDB and, I now understand the significance of secure coding techniques, such as error handling, input validation, and application data protection. My ePortfolio contains three upgraded projects that demonstrate my technical development. The first is a C++ Client Management System that shows my skills in software engineering by enhancing the functionality and organization of the code. The second is an Android warehouse inventory application that uses tools for sorting, searching, and inventory management to show how well I understand algorithms and data structures. The third is a Python and MongoDB Animal Shelter application that showcases my database expertise through enhanced error handling, database connectivity, and CRUD operations. Completing these enhancements has improved my capacity to evaluate current software, pinpoint problem areas, and put fixes in place. Additionally, I have developed expertise in error troubleshooting, application testing, and technical change documentation. My career objective is to become a software developer and keep improving my problem-solving and programming skills. This ePortfolio shows how far I have come in the Computer Science program and how prepared I am to use these abilities in a professional environment.
