Introduction

Professional Self-Assessment

Throughout my Computer Science program at Southern New Hampshire University, I have developed skills in software development, programming, databases, algorithms, and security. Completing this program has helped me become more confident in solving technical problems and preparing for a career as a software developer. My ePortfolio demonstrates the knowledge I have gained and the improvements I have made to projects throughout my education.

My coursework has taught me the importance of collaboration and communication in software development. I have learned how to explain technical decisions, document my work, and consider the needs of users and stakeholders. Through software design documents, code reviews, and project planning, I have developed communication skills that will help me work with other developers and contribute to professional projects.

I have also gained experience with data structures, algorithms, and software engineering. My projects have involved languages such as C++, Java, JavaScript, and Python. I have learned how to organize code, improve functionality, and develop applications that solve practical problems. Courses involving web development and mobile applications have helped me understand how different technologies work together to create complete software solutions.

Database development has been another important part of my education. Working with MongoDB and Python has helped me understand how to store, retrieve, update, and delete information efficiently. I have also learned the importance of secure coding practices, including input validation, error handling, and protecting application data.

My ePortfolio includes three enhanced projects that demonstrate my technical growth. The first is a C++ Client Management System that showcases my software engineering skills through improvements to code organization and functionality. The second is an Android Warehouse Inventory Application that demonstrates my understanding of algorithms and data structures through searching, sorting, and inventory management features. The third is a Python and MongoDB Animal Shelter application that demonstrates my database skills through improved CRUD operations, database connectivity, and error handling.

Completing these enhancements has strengthened my ability to analyze existing software, identify areas for improvement, and implement solutions. I have also gained experience troubleshooting errors, testing applications, and documenting technical changes.

My professional goal is to become a software developer and continue improving my programming and problem-solving skills. This ePortfolio represents my progress throughout the Computer Science program and demonstrates my readiness to apply these skills in a professional environment.
